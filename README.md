# 🌱 Personal Learning Tracker

> Track your daily learning progress, build consistent habits, and stay motivated.

**Personal Learning Tracker** is a browser-based personal application that helps you organize and track your daily learning activities. It provides a visual overview of your progress so you can monitor your learning consistency over time.

🚀 **Live Demo:** [View Personal Learning Tracker](https://tasfia-nowrin.github.io/Personal-Learning-Tracker/)


## ✨ Features

- 📊 **Progress Dashboard** — View your learning progress at a glance.
- ✅ **Daily Task Tracking** — Track three daily learning tasks.
- 🗓️ **Monthly Activity Map** — Visualize your daily activity throughout the month.
- 📖 **Daily Ledger** — Review your learning activity for previous days.
- 🎯 **Progress Target** — Monitor your progress toward your learning goals.
- 🌙 **Light and Dark Mode** — Switch between themes.
- 📄 **PDF Report** — Export or print your progress report.
- 💾 **Local Storage** — Save your progress in your browser.
- 🔒 **Date Restrictions** — Previous days are read-only, and future days are locked.
- ⌨️ **Keyboard Shortcuts** — Use keys `1`, `2`, and `3` to interact with daily tasks.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/tasfia-Nowrin/Personal-Learning-Tracker.git
```

### 2. Open the Project

Go to the project folder:

```bash
cd Personal-Learning-Tracker
```

Open `index.html` in your web browser.

No backend server or database setup is required.


## 📖 How to Use

1. Open the application in your browser.
2. Track your daily learning tasks.
3. Check the dashboard to see your progress.
4. Review your monthly activity map.
5. Switch between light and dark themes.
6. Export or print your progress report when needed.


## 💾 Data Storage

The application uses your browser's **Local Storage** to save your learning progress. Your saved data remains available in the same browser unless the browser data is cleared or the stored data is otherwise removed.

Your data is not automatically synchronized between different browsers or devices.
